# 配置说明

只编辑本目录 `config.json`，保存后完全退出并重启游戏。无需修改两个 `main.js`。JSON 使用英文双引号，不添加注释；每项之间保留英文逗号。升级前备份自己的配置。

## 替换目标

- `replacement.enabled`：`true` 开启换怪，`false` 关闭。
- `replacement.monsterId`：要换成的目标怪物类 ID，默认 `BP_Monster_MoTian_LongZhu_04_C`（当前金面具）。也可填写完整蓝图类路径。

示例：

```json
"replacement": {
  "enabled": true,
  "monsterId": "BP_Monster_AHua_GuiTouDao_C"
}
```

此例把目标改成新娘阿花。不要同时开启旧版阿花换怪脚本。

可在 `monster-ids.json` 搜索 ID；每个 ID 右侧是完整路径。例如上例为：

```text
/PBZCombatAsset/ActorData/Mobs/042_AHua/BP_Monster_AHua_GuiTouDao.BP_Monster_AHua_GuiTouDao_C
```

完整路径必须使用实际文件中的值。索引目前包含388个ID；`BP_Monster_WuLengShuang_C` 存在同名路径，需从索引中选择一条完整路径，不能仅填短ID。自定义或索引未包含的目标也可填写完整路径。

默认金面具已做此前跑图验证；其他目标的动作、尺寸、特殊出场及死亡行为未逐一测试。保留源怪血量/杀气上限，不代表保留其攻击动作与所有行为。炸弹人及特殊遭遇保护继续生效。

## 低血量机制

`lowHpBuff.enabled` 是机制总开关。`damageReduction` 是减伤，`damageBonus` 是增伤；两组各自设置：

| 字段 | 用法 |
|---|---|
| `enabled` | true开启该项，false关闭；关闭项不写对应属性 |
| `maxPercent` | 满效果时的最大百分比。80代表80%；减伤允许0—100，增伤允许0—1000；0不写该项属性 |
| `startHpPercent` | 血量百分比达到或高于此值时，额外效果为0 |
| `fullHpPercent` | 血量百分比达到或低于此值时，达到maxPercent |

必须满足 `0 <= fullHpPercent < startHpPercent <= 100`。两个阈值之间线性变化，效果按2个百分点量化，且不会超过设置的maxPercent。

例：60%血以下开始减伤，20%血及以下达到最高80%减伤；40%血时约40%减伤：

```json
"damageReduction": {
  "enabled": true,
  "maxPercent": 80,
  "startHpPercent": 60,
  "fullHpPercent": 20
}
```

增伤可以独立使用不同阈值。例如30%血开始、10%血达到50%增伤：

```json
"damageBonus": {
  "enabled": true,
  "maxPercent": 50,
  "startHpPercent": 30,
  "fullHpPercent": 10
}
```

不需要低血量机制时，将 `lowHpBuff.enabled` 设为 `false` 并重启；换怪仍可单独运行。

## 配置错误与确认

配置缺失或JSON损坏：本包两个功能停止运行，不擅自恢复默认开启。
目标ID错误：只停用换怪；单项数值或阈值错误：只停用该效果；日志会给出 `config warning`。

加载确认：
- `ProjectPBZ/Content/Paks/~mods/MoYuanClean.log`：`started v3.13-configurable`，及 `config replacement enabled=... target=...`。
- `ProjectPBZ/Content/Paks/~mods/LowHPBuff.log`：`started v3.13-configurable`，及 `config lowHpBuff=...`。

这些百分比是本机制的目标值。装备、原生临时效果和修改器可能使实际属性或伤害不同；本版没有更改既有属性运算方式。配置接入已做静态与模拟验证，游戏内尚未验证。
