# 开发与打包

## 目录

- `ProjectPBZ/PBZModLoader/mods/`：发布源码、默认配置和怪物路径索引。
- `tests/`：无需游戏的配置与回归模拟。
- `dev/PBZMoYuanBirthProbe/`：可选只读出生事件探针，不进入发布包。
- `scripts/package.py`：按显式白名单生成发布包。
- `dist/`：本地生成的ZIP与SHA256，不提交Git。
- `.local/`：仅本机参考资料和回滚脚本，不上传，不参与打包。

## 验证

需要Node.js和Python 3.9+，无需安装npm依赖。

```text
node tests/config.cjs
node tests/regression.cjs
python scripts/package.py
```

也可用`npm test`和`npm run build`。

测试覆盖配置格式、目标ID、阈值边界、独立开关、HP/杀气独立写入、重试预算、位置漂移诊断、特殊遭遇保护、嵌套UArray解包、委托绑定和解绑。模拟通过不等于游戏运行时验证。

## 实现约束

换怪通过刷怪器Class改写与Despawn/Respawn，再将源数值同步到目标。位置配对仍在使用；成功同步时保存所用源记录快照，用于后续诊断，不把移动后的最近刷怪点当作来源。

不复制未经验证的防御属性；不自动清战斗状态、不修改存档、不关闭游戏原生重生机制。炸弹人族、隐藏/伏击/出场配置及已进战遭遇保留原怪。

配置只在模块加载时读取。低血量增益沿用原属性写入方式；装备、临时增益和修改器叠加语义尚未完全确定。

## 发布范围

只发布本项目代码、文档、默认配置和派生怪物路径索引。发布包明确排除第三方加载器、游戏资源、SDK dump、游戏JS、社区mod源码、存档、日志和本地工具。
